# Design Plan — Claudiu Vladau Landing Page

Folder de pregătire pentru redesign-ul landing page-ului personal **claudiuvladau.com**.

Conține tot ce-i trebuie unui designer (uman sau AI — ex. Claude Design, v0, Lovable) ca să producă o pagină coerentă, interactivă, profesională, fără să fie nevoie să întrebe de zero cine sunt.

---

## Cum se folosește

1. **Începe cu `00_PROMPT_PRINCIPAL.md`** — îl copiezi direct în Claude Design / v0 / orice tool de generare UI. Conține contextul complet plus referințe către celelalte fișiere.
2. **Atașezi celelalte fișiere ca sursă** (sau le copiezi în prompt dacă tool-ul nu acceptă atașamente).
3. Iterezi pe ce returnează design-ul, folosind documentele ca „adevăr de referință".

---

## Structura folder-ului

| Fișier | Ce conține |
|---|---|
| `00_PROMPT_PRINCIPAL.md` | Promptul gata de copy-paste pentru Claude Design |
| `01_BRAND_IDENTITY.md` | Cine sunt, ce reprezint, ton de comunicare |
| `02_PUBLIC_TARGET.md` | Cine ajunge pe pagină, ce caută, ce frici are |
| `03_CONTENT_COPY.md` | Toate textele finale, în română, secțiune cu secțiune |
| `04_STRUCTURA_PAGINI.md` | Arhitectura paginii — secțiuni, ordine, scop |
| `05_ELEMENTE_INTERACTIVE.md` | Micro-interacțiuni, animații, componente dinamice |
| `06_DESIGN_SYSTEM.md` | Culori, tipografie, spacing, componente |
| `07_REFERINTE_VIZUALE.md` | Inspirație vizuală, do's & don'ts |
| `08_CALL_TO_ACTION.md` | Strategie CTA — unde, când, cum convertim |

---

## Versiunea curentă

Pagina existentă: `../index.html` — design dark/navy, funcțional, dar static. Obiectivul redesign-ului este să-l facă **mai interactiv, mai narativ și mai uman**, păstrând tonul profesional.
